Modelo de datos y consultas

Los CSV oficiales se cargan en una base SQLite con un modelo estrella. Encima hay vistas con CTEs y window functions, y una consulta por cada pregunta de negocio. Todo lo que muestra el sitio sale de estas consultas.

Modelo estrella

dim_fecha

  • fecha
  • anio
  • mes
  • trimestre
  • mes_idx
  • etiqueta
1 — N

fact_valor

  • fecha
  • serie_id
  • valor
  • estado
N — 1

dim_serie

  • serie_id
  • nombre
  • grupo
  • region
  • unidad
  • base
  • fuente
  • desfase_meses

3.902 filas en fact_valor (33 series × meses, formato largo). estado = 'sospechoso' marca lo que la QA puso en cuarentena: se guarda pero las vistas no lo usan.

v_variacion

Variación mensual, interanual y acumulada en el año de cualquier serie, con LAG() y control de meses faltantes.

v_inflacion

IPC por región, categoría y rubro con RANK() de picos mensuales e interanuales.

v_salario_real

Salarios deflactados por IPC (dic‑2016 = 100) y caída desde el máximo con MAX() OVER acumulado.

v_poder_compra

Pivote de ingresos y canastas: cuántas CBT compra cada ingreso.

v_salario_usd

Ingresos divididos por el tipo de cambio oficial de cada mes.

v_cobertura

Desde y hasta cuándo hay datos válidos de cada serie, y su rezago.

Una consulta por pregunta

01 ¿Le ganaron los salarios a la inflación entre dic‑2016 y el último mes con datos?

Cómo se lee: indice_real = 100 es el mismo poder de compra que en dic‑2016; 90 es un 10 % menos. var_real_pct es la ganancia (+) o pérdida (-) de poder de compra en todo el período. Cada sector llega hasta su último mes con datos (columna hasta): el privado no registrado se publica con 5 meses de rezago y se fecha en el mes que mide, así que termina antes. maximo / minimo muestran el mejor y el peor momento de cada sector.

Ver el SQL (sql/consultas/01_respuesta_principal.sql) 
-- =====================================================================
-- Pregunta: ¿Le ganaron los salarios a la inflación entre dic-2016 y el último mes con datos?
-- Lectura: indice_real = 100 es el mismo poder de compra que en dic-2016; 90 es un 10 % menos.
-- var_real_pct es la ganancia (+) o pérdida (-) de poder de compra en todo el período.
-- Cada sector llega hasta su último mes con datos (columna hasta): el privado no registrado
-- se publica con 5 meses de rezago y se fecha en el mes que mide, así que termina antes.
-- maximo / minimo muestran el mejor y el peor momento de cada sector.
-- =====================================================================
WITH ultimo AS (
    SELECT serie_id, MAX(fecha) AS fecha
    FROM v_salario_real
    GROUP BY serie_id
),
extremos AS (
    SELECT
        serie_id,
        MAX(indice_real) AS maximo,
        MIN(indice_real) AS minimo
    FROM v_salario_real
    GROUP BY serie_id
)
SELECT
    r.serie_id,
    r.nombre,
    r.etiqueta AS hasta,
    ROUND(r.indice_real, 2) AS indice_real,
    ROUND(r.indice_real - 100, 2) AS var_real_pct,
    ROUND(e.maximo, 2) AS maximo,
    (SELECT etiqueta FROM v_salario_real x WHERE x.serie_id = r.serie_id AND x.indice_real = e.maximo) AS fecha_maximo,
    ROUND(e.minimo, 2) AS minimo,
    (SELECT etiqueta FROM v_salario_real x WHERE x.serie_id = r.serie_id AND x.indice_real = e.minimo) AS fecha_minimo,
    ROUND(100 * r.caida_desde_maximo, 2) AS distancia_al_maximo_pct,
    RANK() OVER (ORDER BY r.indice_real DESC) AS ranking
FROM v_salario_real AS r
JOIN ultimo AS u ON u.serie_id = r.serie_id AND u.fecha = r.fecha
JOIN extremos AS e ON e.serie_id = r.serie_id
ORDER BY ranking;

02 ¿Qué sector salió mejor y cuál peor parado frente a la inflación cada año?

Cómo se lee: var_real_pct compara diciembre contra diciembre del año anterior (el último año, contra el último mes en que hay dato de todos los sectores). Positivo = le ganó a la inflación. mejor / peor: el sector con mejor y peor resultado del año, aunque los dos hayan perdido (o ganado) contra la inflación.

Ver el SQL (sql/consultas/02_ganadores_por_anio.sql) 
-- =====================================================================
-- Pregunta: ¿Qué sector salió mejor y cuál peor parado frente a la inflación cada año?
-- Lectura: var_real_pct compara diciembre contra diciembre del año anterior
-- (el último año, contra el último mes en que hay dato de todos los sectores).
-- Positivo = le ganó a la inflación. mejor / peor: el sector con mejor y peor resultado
-- del año, aunque los dos hayan perdido (o ganado) contra la inflación.
-- =====================================================================
WITH ultimo_comun AS (
    -- último mes con dato de todos los sectores: así el último año compara el mismo período
    SELECT MIN(hasta) AS fecha
    FROM (
        SELECT serie_id, MAX(fecha) AS hasta
        FROM v_salario_real
        WHERE serie_id <> 'sal_registrado'
        GROUP BY serie_id
    )
),
cierre AS (
    -- un punto por año: diciembre, o el último mes común del último año
    SELECT serie_id, nombre, anio, fecha, indice_real
    FROM (
        SELECT
            r.*,
            ROW_NUMBER() OVER (PARTITION BY serie_id, anio ORDER BY fecha DESC) AS orden
        FROM v_salario_real AS r
        WHERE r.serie_id <> 'sal_registrado'
          AND r.fecha <= (SELECT fecha FROM ultimo_comun)
    )
    WHERE orden = 1
),
anual AS (
    SELECT
        serie_id,
        nombre,
        anio,
        fecha,
        100 * (indice_real / LAG(indice_real) OVER (PARTITION BY serie_id ORDER BY anio) - 1) AS var_real_pct
    FROM cierre
),
ranking AS (
    SELECT
        a.*,
        RANK() OVER (PARTITION BY anio ORDER BY var_real_pct DESC) AS puesto,
        COUNT(*) OVER (PARTITION BY anio) AS sectores
    FROM anual AS a
    WHERE var_real_pct IS NOT NULL
      AND serie_id <> 'sal_total'
),
total AS (
    SELECT anio, var_real_pct FROM anual WHERE serie_id = 'sal_total'
)
SELECT
    r.anio,
    (SELECT d.etiqueta FROM dim_fecha AS d
     WHERE d.fecha = (SELECT MAX(x.fecha) FROM ranking AS x WHERE x.anio = r.anio)) AS hasta,
    ROUND(MAX(CASE WHEN r.serie_id = 'sal_privado' THEN r.var_real_pct END), 2) AS privado_registrado,
    ROUND(MAX(CASE WHEN r.serie_id = 'sal_publico' THEN r.var_real_pct END), 2) AS publico,
    ROUND(MAX(CASE WHEN r.serie_id = 'sal_no_registrado' THEN r.var_real_pct END), 2) AS no_registrado,
    ROUND(MAX(t.var_real_pct), 2) AS total,
    MAX(CASE WHEN r.puesto = 1 THEN r.nombre END) AS ganador,
    MAX(CASE WHEN r.puesto = r.sectores THEN r.nombre END) AS perdedor
FROM ranking AS r
LEFT JOIN total AS t ON t.anio = r.anio
GROUP BY r.anio
ORDER BY r.anio;

04 ¿Cuánta inflación hubo cada año y qué la empujó: núcleo, regulados o estacionales?

Cómo se lee: variación diciembre contra diciembre (el último año: acumulada hasta el último mes). regulados - nucleo > 0 indica que las tarifas y precios regulados subieron más que el resto.

Ver el SQL (sql/consultas/04_inflacion_anual_por_categoria.sql) 
-- =====================================================================
-- Pregunta: ¿Cuánta inflación hubo cada año y qué la empujó: núcleo, regulados o estacionales?
-- Lectura: variación diciembre contra diciembre (el último año: acumulada hasta el último mes).
-- regulados - nucleo > 0 indica que las tarifas y precios regulados subieron más que el resto.
-- =====================================================================
WITH cierre AS (
    SELECT
        serie_id,
        anio,
        fecha,
        var_acumulada_anio,
        ROW_NUMBER() OVER (PARTITION BY serie_id, anio ORDER BY fecha DESC) AS orden
    FROM v_variacion
    WHERE serie_id IN ('ipc_nacional', 'ipc_nucleo', 'ipc_regulados', 'ipc_estacionales')
      AND var_acumulada_anio IS NOT NULL
)
SELECT
    anio,
    (SELECT d.etiqueta FROM dim_fecha AS d
     WHERE d.fecha = (SELECT MAX(x.fecha) FROM cierre AS x WHERE x.anio = cierre.anio AND x.orden = 1)) AS hasta,
    ROUND(100 * MAX(CASE WHEN serie_id = 'ipc_nacional' THEN var_acumulada_anio END), 2) AS nivel_general,
    ROUND(100 * MAX(CASE WHEN serie_id = 'ipc_nucleo' THEN var_acumulada_anio END), 2) AS nucleo,
    ROUND(100 * MAX(CASE WHEN serie_id = 'ipc_regulados' THEN var_acumulada_anio END), 2) AS regulados,
    ROUND(100 * MAX(CASE WHEN serie_id = 'ipc_estacionales' THEN var_acumulada_anio END), 2) AS estacionales,
    ROUND(100 * (MAX(CASE WHEN serie_id = 'ipc_regulados' THEN var_acumulada_anio END)
               - MAX(CASE WHEN serie_id = 'ipc_nucleo' THEN var_acumulada_anio END)), 2) AS regulados_menos_nucleo
FROM cierre
WHERE orden = 1
GROUP BY anio
ORDER BY anio;

05 ¿Qué rubros del IPC subieron más y cuáles menos?

Cómo se lee: acumulado_desde_dic2016_pct = cuánto subió cada rubro desde la base; veces = cuántas veces se multiplicó el precio (índice / 100). ultimo_anio_pct = variación interanual del último mes. acumulado_vs_general_pct = cuánto más caro (o más barato) quedó el rubro que el nivel general, en % (cociente de índices); ultimo_anio_vs_general_pp = interanual del rubro menos la del nivel general, en puntos porcentuales. Positivo = el rubro se encareció más que el promedio.

Ver el SQL (sql/consultas/05_rubros_ranking.sql) 
-- =====================================================================
-- Pregunta: ¿Qué rubros del IPC subieron más y cuáles menos?
-- Lectura: acumulado_desde_dic2016_pct = cuánto subió cada rubro desde la base;
-- veces = cuántas veces se multiplicó el precio (índice / 100).
-- ultimo_anio_pct = variación interanual del último mes.
-- acumulado_vs_general_pct = cuánto más caro (o más barato) quedó el rubro que el nivel general,
-- en % (cociente de índices); ultimo_anio_vs_general_pp = interanual del rubro menos la del
-- nivel general, en puntos porcentuales. Positivo = el rubro se encareció más que el promedio.
-- =====================================================================
WITH ultimo AS (
    SELECT MAX(fecha) AS fecha FROM v_variacion WHERE grupo = 'ipc_rubro'
),
general AS (
    SELECT valor, var_interanual
    FROM v_variacion
    WHERE serie_id = 'ipc_nacional' AND fecha = (SELECT fecha FROM ultimo)
)
SELECT
    RANK() OVER (ORDER BY v.valor DESC) AS puesto_acumulado,
    v.nombre AS rubro,
    v.etiqueta AS hasta,
    ROUND(v.valor / 100, 1) AS veces,
    ROUND(v.valor - 100, 1) AS acumulado_desde_dic2016_pct,
    ROUND(100 * (v.valor / g.valor - 1), 1) AS acumulado_vs_general_pct,
    RANK() OVER (ORDER BY v.var_interanual DESC) AS puesto_ultimo_anio,
    ROUND(100 * v.var_interanual, 2) AS ultimo_anio_pct,
    ROUND(100 * (v.var_interanual - g.var_interanual), 2) AS ultimo_anio_vs_general_pp
FROM v_variacion AS v
CROSS JOIN general AS g
WHERE v.grupo = 'ipc_rubro'
  AND v.fecha = (SELECT fecha FROM ultimo)
ORDER BY puesto_acumulado;

06 ¿Cuántas Canastas Básicas Totales compran el salario promedio (RIPTE), el salario mínimo y la jubilación mínima?

Cómo se lee: CBT de un adulto equivalente en GBA. Menos de 1 = ese ingreso no alcanza para que una sola persona adulta supere la línea de pobreza. Un punto por año (diciembre) más el último mes con todas las series.

Ver el SQL (sql/consultas/06_poder_compra_canastas.sql) 
-- =====================================================================
-- Pregunta: ¿Cuántas Canastas Básicas Totales compran el salario promedio (RIPTE),
-- el salario mínimo y la jubilación mínima?
-- Lectura: CBT de un adulto equivalente en GBA. Menos de 1 = ese ingreso no alcanza
-- para que una sola persona adulta supere la línea de pobreza.
-- Un punto por año (diciembre) más el último mes con todas las series.
-- =====================================================================
WITH completo AS (
    SELECT *
    FROM v_poder_compra
    WHERE ripte IS NOT NULL AND smvm IS NOT NULL AND haber_minimo IS NOT NULL
),
ultimo AS (
    SELECT MAX(fecha) AS fecha FROM completo
)
SELECT
    etiqueta AS mes,
    ROUND(cbt, 2) AS cbt_pesos,
    ROUND(cbt_por_ripte, 2) AS cbt_por_ripte,
    ROUND(cbt_por_smvm, 2) AS cbt_por_salario_minimo,
    ROUND(cbt_por_haber_minimo, 2) AS cbt_por_jubilacion_minima,
    CASE WHEN fecha = (SELECT fecha FROM ultimo) THEN 1 ELSE 0 END AS es_ultimo
FROM completo
WHERE mes = 12 OR fecha = (SELECT fecha FROM ultimo)
ORDER BY fecha;

07 ¿En qué región del país subieron más los precios?

Cómo se lee: acumulado desde dic‑2016 e interanual del último mes por región, con su puesto. diferencia_vs_pais_pp = puntos porcentuales por encima (+) o debajo (-) del total país.

Ver el SQL (sql/consultas/07_regiones.sql) 
-- =====================================================================
-- Pregunta: ¿En qué región del país subieron más los precios?
-- Lectura: acumulado desde dic-2016 e interanual del último mes por región, con su
-- puesto. diferencia_vs_pais_pp = puntos porcentuales por encima (+) o debajo (-) del total país.
-- =====================================================================
WITH ultimo AS (
    SELECT MAX(fecha) AS fecha FROM v_variacion WHERE grupo = 'ipc_region'
),
pais AS (
    SELECT var_interanual FROM v_variacion
    WHERE serie_id = 'ipc_nacional' AND fecha = (SELECT fecha FROM ultimo)
)
SELECT
    v.region,
    v.nombre,
    v.etiqueta AS hasta,
    ROUND(v.valor - 100, 1) AS acumulado_desde_dic2016_pct,
    RANK() OVER (ORDER BY v.valor DESC) AS puesto_acumulado,
    ROUND(100 * v.var_interanual, 2) AS interanual_pct,
    RANK() OVER (ORDER BY v.var_interanual DESC) AS puesto_interanual,
    ROUND(100 * (v.var_interanual - p.var_interanual), 2) AS diferencia_vs_pais_pp
FROM v_variacion AS v
CROSS JOIN pais AS p
WHERE v.grupo = 'ipc_region'
  AND v.fecha = (SELECT fecha FROM ultimo)
ORDER BY CASE WHEN v.region = 'nacional' THEN 0 ELSE 1 END, puesto_acumulado;

08 ¿Cuánto vale el salario en dólares oficiales y cómo cambió?

Cómo se lee: promedio anual del RIPTE, del salario mínimo y de la jubilación mínima divididos por el tipo de cambio oficial de valuación del BCRA de cada mes. El año en curso promedia solo los meses disponibles (columna meses).

Ver el SQL (sql/consultas/08_salario_en_dolares.sql) 
-- =====================================================================
-- Pregunta: ¿Cuánto vale el salario en dólares oficiales y cómo cambió?
-- Lectura: promedio anual del RIPTE, del salario mínimo y de la jubilación mínima
-- divididos por el tipo de cambio oficial de valuación del BCRA de cada mes.
-- El año en curso promedia solo los meses disponibles (columna meses).
-- =====================================================================
SELECT
    anio,
    COUNT(*) AS meses,
    ROUND(AVG(ripte_usd), 0) AS ripte_usd,
    ROUND(AVG(smvm_usd), 0) AS salario_minimo_usd,
    ROUND(AVG(haber_minimo_usd), 0) AS jubilacion_minima_usd,
    ROUND(AVG(tc_oficial), 2) AS tipo_cambio_promedio
FROM v_salario_usd
WHERE ripte_usd IS NOT NULL
  AND anio >= 2017
GROUP BY anio
ORDER BY anio;

09 ¿Hasta qué mes vale cada conclusión?

Cómo se lee: las series se publican con rezagos distintos; cada análisis llega hasta el último mes en que TODAS sus series tienen dato válido (sin valores a futuro ni sospechosos). El privado no registrado va aparte: el INDEC lo publica con 5 meses de rezago y acá se fecha en el mes que mide, así que termina antes que el resto de los salarios.

Ver el SQL (sql/consultas/09_vigencia_de_conclusiones.sql) 
-- =====================================================================
-- Pregunta: ¿Hasta qué mes vale cada conclusión?
-- Lectura: las series se publican con rezagos distintos; cada análisis llega hasta el
-- último mes en que TODAS sus series tienen dato válido (sin valores a futuro ni sospechosos).
-- El privado no registrado va aparte: el INDEC lo publica con 5 meses de rezago y acá se
-- fecha en el mes que mide, así que termina antes que el resto de los salarios.
-- =====================================================================
WITH alcance (analisis, grupo, solo_serie, sin_serie) AS (
    VALUES
        ('Salario real: total, registrados, privado y público', 'salario_indice', NULL, 'sal_no_registrado'),
        ('Salario real: total, registrados, privado y público', 'ipc_region', NULL, NULL),
        ('Salario real: privado no registrado', 'salario_indice', 'sal_no_registrado', NULL),
        ('Salario real: privado no registrado', 'ipc_region', NULL, NULL),
        ('Inflación, rubros y regiones', 'ipc_region', NULL, NULL),
        ('Inflación, rubros y regiones', 'ipc_categoria', NULL, NULL),
        ('Inflación, rubros y regiones', 'ipc_rubro', NULL, NULL),
        ('Poder de compra en canastas', 'ingreso_pesos', NULL, NULL),
        ('Poder de compra en canastas', 'canasta', NULL, NULL),
        ('Salario en dólares', 'ingreso_pesos', NULL, NULL),
        ('Salario en dólares', 'tipo_cambio', NULL, NULL)
)
SELECT
    a.analisis,
    MIN(c.hasta) AS vale_hasta,
    GROUP_CONCAT(DISTINCT c.grupo) AS grupos,
    MAX(c.meses_de_rezago) AS rezago_maximo_meses
FROM alcance AS a
JOIN v_cobertura AS c
    ON c.grupo = a.grupo
    AND (a.solo_serie IS NULL OR c.serie_id = a.solo_serie)
    AND (a.sin_serie IS NULL OR c.serie_id <> a.sin_serie)
GROUP BY a.analisis
ORDER BY vale_hasta, a.analisis;
